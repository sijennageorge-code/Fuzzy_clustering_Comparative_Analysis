# Fuzzy Clustering Comparative Analysis of Cosmetic Ingredients

## Overview

Developed during my internship at **ITC Life Sciences & Technology Centre (LSTC)** to analyse similarity patterns among cosmetic ingredients using unsupervised machine learning.

## Methods

* Data preprocessing and feature scaling
* **Fuzzy C-Means Clustering**
* **Principal Component Analysis (PCA)**
* Interactive **R/Shiny dashboard**

## Tools

**R | Shiny | PCA | Fuzzy Clustering | ggplot2 | Plotly | DT**

## Project Structure

* `data_cleaning.R` — Data preprocessing and preparation
* `dashboard.R` — Shiny dashboard and visualization

## Key Outcome

Identified similarity patterns among cosmetic ingredients through fuzzy clustering and PCA, and developed an interactive dashboard for exploring the results.
